
# 🌍 Civilization of Wonders — Installation Guide

**Build your own world. Connect your own database. Host your own website.**

> A step-by-step guide for developers who want to clone Civilization of Wonders (CoW) and configure their own application.

---

## 📚 Installation Guide

The installation documentation is divided into parts so that completed setup instructions remain stable while new integrations are developed.

### 📘 [Part 1 — Development Environment](INSTALLATION-GUIDE-PART-1.md)

**Status: Completed**

Learn how to:

- Prepare your development environment.
- Clone the GitHub repository.
- Install npm dependencies.
- Configure the local `midgard-hex-grid` dependency.

### 📗 [Part 2 — Convex Database](INSTALLATION-GUIDE-PART-2.md)

**Status: In progress**

Learn how to:

- Create your own Convex cloud project.
- Configure environment variables.
- Configure Git and Convex-generated files.
- Connect TypeScript to Convex.
- Define the database schema.
- Initialize twelve permanent worlds.
- Prepare the database for hexagon storage.

### 📙 Part 3 — Authentication and Hosting

**Status: Planned**

Future documentation may cover:

- Clerk authentication.
- Google sign-in.
- Map ownership and authorization.
- Vercel deployment.
- Custom domain configuration.

Part 3 will be created when development reaches those features. Additional parts may be introduced if necessary.

---

## 🎯 Installation Goal

A completed installation should provide:

- Your own copy of the source code.
- Your own Convex project and database.
- Twelve permanent worlds.
- Hexagonal terrain storage.
- User authentication and map ownership.
- Real-time synchronization.
- A deployed website.

Every developer should be able to configure these services using their own accounts and credentials.
